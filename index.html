01 / PROJECT OVERVIEW

Everyday appliances,
one connected interface.

HomeFlow connects a web-based control panel to physical appliances through an ESP32 and a relay module. The ESP32 joins the home Wi-Fi network and starts a web server on port 80. A browser on the same network sends an HTTP request to an appliance-specific route; the firmware changes the corresponding GPIO output to switch the relay.

CONTROLLED DEVICESLamp · Speaker · Coffee Machine
PROJECT INTENT

Integrate embedded firmware, local networking, browser controls and relay-based appliance switching.

04 / FIRMWARE & NETWORKING

Small HTTP routes.
Direct hardware control.

1. Connect to Wi-Fi
ESP32 joins the configured network.

2. Start server
WebServer server(80) listens for HTTP requests.

3. Register routes
Separate ON/OFF endpoints are registered per appliance.

4. Switch output
LOW turns the relay ON; HIGH turns it OFF in the supplied sketch.

// Credentials intentionally redacted
const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";

#define RELAY_LAMP    27
#define RELAY_SPEAKER 26
#define RELAY_COFFEE  25

server.on("/lamp/on", lampOn);
server.on("/lamp/off", lampOff);
server.on("/speaker/on", speakerOn);
server.on("/speaker/off", speakerOff);
server.on("/coffee/on", coffeeOn);
server.on("/coffee/off", coffeeOff);

void lampOn() {
  digitalWrite(RELAY_LAMP, LOW);
  server.send(200, "text/plain", "Lamp ON");
}
